# پیشرو سرمایه — لندینگ (۱۳ نسخه طراحی)

Static Claude Design handoff for Pishro Capital landing-page variants.

## Preview

```bash
python3 -m http.server 4173
```

Open [http://localhost:4173/](http://localhost:4173/) (redirects to the version index).

| File | Role |
|------|------|

| `فهرست نسخهها.dc.html` | Index of all 13 versions |

| `نسخه ۱۱` | Kinetic typography (2026 trend) |
| `نسخه ۱۲` | Tactile brutalism (2026 trend) |
| `نسخه ۱۳` | Apple glass / iPhone aesthetic |

Shared palette: navy `#0B2A4A`, emerald `#12A47A`, warm neutrals.
