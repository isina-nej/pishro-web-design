# پیشرو سرمایه — لندینگ (۱۰ نسخه طراحی)

Static Claude Design handoff for Pishro Capital landing-page variants.

## Preview

```bash
python3 -m http.server 4173
```

Open [http://localhost:4173/](http://localhost:4173/) (redirects to the version index).

## Files

| File | Role |
|------|------|
| `support.js` | Claude Design (`dc-runtime`) client |
| `فهرست نسخهها.dc.html` | Index of all 10 versions |
| `نسخه ۱ … ۱۰ - *.dc.html` | Landing design variants |

Shared palette: navy `#0B2A4A`, emerald `#12A47A`, warm neutrals.
